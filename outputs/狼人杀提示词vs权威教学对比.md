# 狼人杀提示词 vs 权威教学 逐条对比

> 对比对象：项目 `prompt/` 下的读人框架（ReadingTells）、基本打法（strategyBrief）、各身份 Kit、狼队战术、板子打法、阶段任务。
> 权威来源：狼人杀官方攻略（预言家/女巫/猎人/守卫/平民）、狼人杀爱好者站（真假预言家、狼人打法、轮次理论）、网易/微信高赞教学。
> 标记：✅ 已覆盖 ｜ ⚠️ 有偏差（写反/过头/不够准） ｜ ❌ 缺失 ｜ 🗑️ 我们多写的错误。

## 一、预言家 / 找真预言家

| 权威判据 | 我们 | 结论 |
|---|---|---|
| 预言家报查验 + 警徽流 + 心路「三部曲」，缺一不可；但忘记说不能否定身份，只是不给警徽票 | 报验人、警徽流、验人逻辑都教了；首夜例外也教了 | ✅ |
| **真预言家验人理由通常朴素**（身边开摸、听发言像狼）；理由牵强才需谨慎 | 我们写「第 2 夜起真预言家能讲清为什么验、悍跳只报一句」，方向对；但**首夜那条我们已改成「心路不算证据」**，与权威一致 | ✅ 已修正 |
| **判断真假是三维一体**：① 查验/警徽流合理性 ② 票型与团队（狼集体冲票给悍跳；警惕过于积极站真预的倒钩狼）③ 逻辑动机 | 我们侧重①，票型有「谁跟谁投」，但**没有「看警徽票来源判断团队脏不脏」「警惕倒钩狼」** | ❌ 缺团队/票型维度 |
| **悍跳狼破绽**：警徽流模糊（随便验/看心情）、只猛打对跳不分析别人、过早绑定队友、验人理由牵强 | 我们有「奔着狼留、不敢验发言差的人」；但没有「只打对跳不打全场 = 视角狭窄」 | ⚠️ 部分 |
| **警徽流要防自爆**（警下多验一个备选） | 完全没提 | ❌ |
| **不要验一张已经被自己定义过的牌**（定义成冲锋狼又流进警徽流 = 逻辑倒错） | 完全没有；我们反而写「验发过言的人不是错」（虽不算错，但漏了这条更精确的判据） | ❌ |
| 发言状态/心态：真预言家思考痕迹、焦急但克制；狼准备过度显得流畅机械 | 我们有「话术工整不等于真」「心路流畅不算证据」，方向一致 | ✅ 偏保守但没错 |
| 后置位起跳（前置无人跳）可信度较高 | 没有 | ❌ |
| 金水力度/查杀力度随板型变化（不同板子查杀力度不同） | 完全没有 | ❌ |
| 第一天若猎人对跳，猎人是当天轮次（可当场翻牌自证），真预可留到第二天 | 完全没有 | ❌ |
| 预言家死前改警徽流、警徽移交对象，是倒牌后的关键判断 | 引擎有警徽移交机制，但读人框架没有「从移交看真假」 | ❌ |

## 三、女巫

| 权威判据 | 我们 | 结论 |
|---|---|---|
| 解药前藏身份，以村民视角发言，不能泄露刀位（「爆神式发言」会被当聊爆狼或第一刀） | 我们写「不要说救过谁/毒过谁/用我昨晚听说暗示」，方向对，但没有「泄露刀位=聊爆狼」这个后果 | ⚠️ |
| **建议首夜开药**（避免神职猝死、狼领先一轮）；怕自刀可不开，见仁见智 | 我们写「首夜救人，解药留着更亏」（任务层），但女巫 Kit 写「毒药宁可留到确定是狼那天；救人也只救确定该救的，别因他好像挺重要浪费解药」——**首夜解药这条我们不够明确** | ⚠️ |
| 用过解药后**阳光起跳报银水**，帮好人确定两张好人牌 | 我们只有「被查杀且平安夜时可跳女巫报银水自证」这个逃生门；**没有「用了解药就起跳报银水带队」这条常规打法** | ❌ |
| 毒药慎用，除非确定是狼；毒错平民给狼送优势，毒死猎人/预言家锅更大 | 已写入 | ✅ |
| **有人穿女巫衣服（跳女巫），真女巫夜里毒死他** | 没有 | ❌ |
| 银水大概率好人但不可轻信（狼自刀骗药），要结合发言验证 | 已写入（notes：救过的不一定是好人） | ✅ |
| 被首刀无法自救，应上警告知好人「女巫首刀」信息 | 没有 | ❌ |
| 捏毒威慑（起跳带队归票疑似狼，用毒逼狼暴露） | 没有 | ❌ |
| 与守卫配合：同守同救会死，首夜建议守卫空守、女巫开药 | 引擎有守救同归规则；但女巫 Kit 没提「首夜让守卫空守、自己开药」的配合 | ⚠️ |

## 四、猎人

| 权威判据 | 我们 | 结论 |
|---|---|---|
| 翻牌前不报身份（提前跳=浪费技能） | 已写入 | ✅ |
| 开枪带走最怀疑的狼，不是声音最大/骂得最凶 | 已写入 | ✅ |
| 开枪顺序：对跳猎人 > 查杀你的狼 > 确认的狼 > 中后期怀疑的狼；**首刀无信息时可选择不开枪（黑枪）** | 我们有「深水狼→冲锋狼」的顺序，**没有对跳猎人优先、也没有黑枪选项** | ❌ |
| 猎人可以**声称死后会带谁**给狼施压、赌心态、获取信息（枪徽流） | 完全没有 | ❌ |
| 被查杀后跳猎人身份 = 帮狼找神，很多好人会要求你出局自证；应认民视角发言 | 没有；我们只写「翻牌前不报身份」 | ❌ |
| 一只狼在场时，狼常赌猎人心理孤注一掷——猎人要数清场上狼数再开枪 | 没有 | ❌ |
| 吃毒不能开枪，感觉要吃毒时跳明身份（最差被公投出局，还能翻枪） | 我们写「被毒死不能开枪」是规则，但没有「感觉要吃毒就跳明」的应对 | ❌ |
| 首刀/首毒时跳出来表明身份，防止狼穿猎人衣服 | 没有 | ❌ |

## 五、守卫

| 权威判据 | 我们 | 结论 |
|---|---|---|
| 首夜**主流是空守**（女巫会盲救，撞了守救同归 = 医疗事故）；自守是另一种思路但降低第二晚灵活性 | 我们写「优先守最像预言家的，必要时守自己」、TaskBriefs 写「空守等于白过，除非确信狼空刀」——**与主流权威打法相反！** 权威说首夜空守是好打法，我们把它贬成「白过」 | 🗑️ **写反了** |
| 不能连守同一人 | 已写入 | ✅ |
| 第二晚：真假预言家都在→不守预言家，优先自守/守明好人；单边预言家→守预言家拿两晚警徽流 | 完全没有这种分情况 | ❌ |
| 第三晚起判断神少还是民少；外置位守出平安夜，第二天基本空守（狼会追刀） | 没有 | ❌ |
| 最高优先守护 = 双药女巫/预言家，其次明好人 | 我们写「优先守最像预言家的，必要时守自己」，**漏了双药女巫优先级最高** | ⚠️ |
| 女巫出局前守卫不跳明；女巫出局/药空后再考虑明跳报守人顺序 | 我们写「不要报守过谁」，但没写「什么时候可以明跳、怎么报」 | ⚠️ |
| 预言家明确要求守他时，可反其道自守（狼会以为你守预而来刀你） | 没有 | ❌ |
| 被怀疑时过度解释本身是破绽，一句「我没信息」就够 | 已写入 | ✅ |

## 六、平民

| 权威判据 | 我们 | 结论 |
|---|---|---|
| 尽早站边、统一票型，避免分票；站错可改回，但不能不站 | 我们写「别弃票」，但没有「站错边要能站回来」和「尽早站边」 | ⚠️ |
| **不能认推**（主动要求出自己 = 白送轮次，身份也不会变高）；任务是「谁出局也不能是我」 | 完全没有 | ❌ |
| 划水坐低身份，是最容易被扛推的理由；要用闭眼视角把心路讲饱满 | 我们有「每一轮带来新东西」，方向对但没点破「划水=扛推位」 | ⚠️ |
| 不要在发言里「找神/点神」（帮狼点刀，身份做差） | 完全没有 | ❌ |
| 不要做暴民（乱穿衣服、逻辑没盘明白就踩人）；平民点神=帮狼点刀 | 没有 | ❌ |
| 警上可以**诈身份**（给后置位发查杀看谁心虚）；被诈可穿神牌逼退水 | 我们在警上条目写了诈身份 vs 悍跳看退水，但那是「怎么识别」，**没教平民可以主动诈身份** | ⚠️ |
| 发言观点先行（先结论后理由） | TaskBriefs 的骨架就是结论先行 | ✅ |
| 言行不一（说投 A 投了 B）= 大概率狼 | 已写入（票是硬证据） | ✅ |

## 七、轮次理论（我们最缺的一整块）

| 权威判据 | 我们 | 结论 |
|---|---|---|
| **轮次优先级：查杀 > 对跳 > 行为 > 发言**；每天有既定放逐轮次 | 完全没有 | ❌ |
| 第一天一定是真假预言家及其查杀的轮次；外置位发言不好的人只能「吃验/毒/枪/明天再推」 | 完全没有 | ❌ |
| **有查杀走查杀**：预言家在出掉自己查杀前不能出对跳，防「狼查杀狼」做身份 | 完全没有，且我们的「被查杀者表水」判据可能与此冲突（见下） | ❌ |
| 放逐顺序：查杀 > 悍跳狼 > 冲锋狼 > 行为不好 > 倒钩狼 > 深水狼 | 完全没有 | ❌ |
| **分票是典型的狼人行为**；不确定时宁可弃票，不要无理由乱投 | 我们有「弃票白送票」，但**权威说分不清时可以弃票、不要乱投**——我们写得过绝 | ⚠️ |
| 警推领先时好人拍身份裸打；狼刀领先时神牌隐藏、大家一起认民挡刀 | 完全没有 | ❌ |
| 身份牌起跳顺序应与狼的理想刀人顺序相反（女巫>预言家>白痴>猎人 是狼的刀序） | 完全没有 | ❌ |
| **不到你的轮次不要拍身份**（防狼抿神）；首夜有查杀的查杀位才拍身份表水 | 我们有「神职不要主动报身份」，但没有「轮次」这个判断框架 | ⚠️ |

## 八、狼人战术

| 权威判据 | 我们 | 结论 |
|---|---|---|
| 五种基础战术：悍跳/冲锋/倒钩/深水/自刀 | 都有，且更细（11 种菜单） | ✅ |
| **悍跳狼发言水平通常比真预言家高**（4 选 1，能力经过筛选），所以「流畅」不能作为判真依据 | 我们有「话术工整不等于真」，方向一致 | ✅ |
| 冲锋狼**通过攻击真预言家/站真预的人反向支持**，比直接站边效果好；攻击要有理有据，别太猛引众怒 | 我们有「冲锋要落在具体破绽」，但没有「攻击站真预的人是反向支持」 | ⚠️ |
| 倒钩狼不是简单踩队友，是站在「第三方平民」立场找狼坑、不轻易拉票 | 我们有「倒钩站真预踩队友」，**但缺「第三方视角、不拉票」这个精髓，还容易演成拉票** | ⚠️ |
| 阴阳倒钩：绑定真预同时故意暴露狼面，做低真预身份 | 完全没有 | ❌ |
| 深水狼避免被查验、被女巫针对、避免成为焦点牌 | 我们有 | ✅ |
| 自刀/空刀/双爆的收益与翻车点 | 我们有，且更完整 | ✅ |
| 头狼指挥、队友配合 | 我们有 | ✅ |

## 九、可能「我们写错或写反」的重点（建议优先处理）

1. **守卫首夜空守被我们贬成「白过」** —— 权威主流是空守（女巫盲救，避免守救同归），这是明确写反。
2. **「被查杀者表水」判据与轮次理论冲突** —— 我们写「被查杀后不表水、反砸别人 = 狼面」，但权威说「有查杀走查杀」，首日查杀位本就该先出、其自证未必可信；这局 9 号（真平民被悍跳查杀）正因"不表水"被投出去，我们的判据会重蹈覆辙。
3. **弃票写得过绝** —— 我们说「弃票等于白送」，权威说分不清时宁可弃票、不要无理由乱投。
4. **女巫用解药后应起跳报银水带队** —— 我们只写了自证逃生门，缺常规打法。
5. **警徽流防自爆、不验已定义过的牌** —— 两条精确判据完全缺失。

## 建议的修订优先级

- **P0（写反/会害死好人）**：守卫首夜空守、被查杀者表水 vs 有查杀走查杀、弃票口径。
- **P1（整块缺失）**：轮次理论（查杀>对跳>行为>发言、每天放逐轮次、分票=狼、警推/狼刀领先）。
- **P2（重要判据缺失）**：找真预言家的团队/票型维度、警徽流防自爆与不验已定义牌、女巫报银水带队、猎人枪徽流与黑枪。
- **P3（细节补充）**：后置位起跳可信、金水/查杀力度随板型、平民找神禁忌、阴阳倒钩。
