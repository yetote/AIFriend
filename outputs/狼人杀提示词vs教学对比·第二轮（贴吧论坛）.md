## 一、最重磅：贴吧「大局观（轮次优先）」帖印证了整块轮次理论

来源：百度贴吧《狼人杀心得札记一（新手大局观入门）》——「**新手争发言，高手争轮次**」。

| 贴吧观点 | 我们的现状 | 结论 |
|---|---|---|
| 轮次 = 回合制博弈的「先手权」，多握一轮就有绝对主动权，发言有瑕疵也能靠轮次赢；丢轮次则发言天衣无缝也难翻 | 我们 P1 补了轮次理论，但写的是「放逐优先级/警推领先」，没有点破「轮次=先手权、比发言更重要」这个统摄关系 | 🆕 值得补一句统领 |
| 12 人预女猎白：好人天生领先 1 轮 + 女巫毒药/猎人枪共 3 轮容错；狼天生劣势，唯一稳定轮次来源是夜间刀人，靠白天抢 | 我们没有量化这个初始差距 | 🆕 可补（按板子） |
| **好人丢轮次 90% 发生在白天投票**：被煽动去投发言差的平民/容错牌，分票，狼抱团冲票推走真预言家 | 我们写了「分票是狼人行为」，但没点出「90% 丢轮次在投票环节」这个重心 | 🆕 可补 |
| 投票铁律：**永远投全场最确定的明狼，宁放过一个容错牌，绝不投错一个好人**；场上有明狼时所有票挂明狼、不分票不改票 | 我们写「查杀>对跳」优先级，但没写「宁放过容错牌也不投错好人」这条铁律 | 🆕 值得补 |
| **投错一个平民=狼多一轮；放过容错牌=下轮还能验证** | 没有这个「代价对比」的直白表述 | 🆕 值得补 |
| 神牌技能只为追轮次服务：女巫救药优先留给真预言家守住信息源；**毒药只毒 100% 确定的狼**，毒错好人=丢一轮甚至崩盘；**猎人宁闷枪不瞎带**，带错好人再无翻盘 | 我们写了女巫毒药慎用、猎人别乱带，但没用「追轮次」把它们统一起来，也没写「救药优先留给真预言家」 | 🆕 值得补（且和 hunters 的「黑枪」印证） |
| 平民：轮次领先时藏好、不乱跳不乱带；落后时跟明神投票不分票。**「不犯错就是最大功劳」「不帮狼送轮次」** | 我们补了「不认推、不找神、不做暴民」，方向一致，但没有「不犯错即功劳」这个统领 | ✅ 方向一致，🆕 可补统领句 |

## 二、网杀经验站：真假预言家判断的新硬判据

| 网杀判据 | 我们的现状 | 结论 |
|---|---|---|
| **上警第一个跳、查杀后置位却发错身份再改口，90%+ 是悍跳狼——真预言家不可能记错自己的验人信息** | 我们有「首夜理由能不能验算」，但没有「验人信息前后改口」这条极硬的判据 | 🆕 **高价值，必补** |
| 验人力度（查杀/金水的"力度"）可作依据但**绝不是站边理由**；悍跳狼故意报查杀好人骗新手信 | 我们有「金水证明不了干净」，但没有「查杀力度也不等于真」这条对称的提醒 | 🆕 可补 |
| **警徽流不能给悍跳狼判死刑，也不能把真预打入狼坑**——训练过的双方都能给完美警徽流 | 我们写「警徽流看兑现」，是对的；但没写「完美警徽流≠真预言家」这层 | 🆕 可补（防止模型迷信） |
| 心路历程是判断真假的重要依据，一旦心路出问题可立刻判假（与报查验、警徽流不同，后两者能靠发言水平搪塞） | 我们首夜把心路「反过来用」，第 2 夜起心路有用——一致；但没写「心路出问题=立刻判假」的力度 | 🆕 可补 |
| **预言家爆水：发言一塌糊涂的，反而最像真预言家**（不是演说家） | 我们有「话术工整不等于真」「别因不够专业打成悍跳」，方向完全一致 | ✅ 已印证 |
| 外置位判断：把自己代入预言家给外置位定义，和起跳者的定义对比，吻合则偏真；但狼会顺好人视角定义、拿队友填狼坑，别武断 | 我们有「别只看他说什么，看谁站背后」，但没有「自己代入预言家对比外置位」这个具体动作 | 🆕 可补 |
| 站边要站**真的预言家，不是发言好的那个** | 我们有「心路流畅不算证据」，一致 | ✅ |

## 六、结论：需要改吗？

**大部分新来源是「印证 + 强化」，不是推翻。** 第一轮改的轮次理论、被查杀者表水、弃票口径、警徽流看兑现、各身份判据，方向全部被新来源支持。

真正值得补的**高价值新点**（按优先级）：

1. **验人信息前后改口 = 90%+ 悍跳**（真预言家不会记错自己的验人）——极硬、极好用。
2. **「轮次=先手权、比发言更重要」的统领句** + **投票铁律：宁放过容错牌、绝不投错好人**（贴吧）。
3. **警徽流不能判死刑、完美警徽流≠真预言家**（防模型迷信单项指标）。
4. **神牌技能为追轮次服务**：女巫救药优先真预言家、毒药只毒 100% 确定的狼、猎人宁闷枪不瞎带。
5. **民诈身份只报后置位查杀、别报金水/警下查杀**；**关键轮次弃票 = 狼面信号**。
6. **银水自刀骗药率 ~40%**（强化力度）；**两个预言家对跳都别毒，除非查杀你**。

**一处需权衡**：女巫首夜开药——我们写「通常开药」，贴吧帖主张「非特殊版子不救首夜未知身份」。两派都有道理，建议保持「看局势、别盲救已知身份不明的牌」，不要写死。
